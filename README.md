# The Haunted Harvest
HTML5 + CSS3 only (no JavaScript). Three chapters switched with `:target`:
Trick-or-Treat Lane, Graveyard Hill, Witches' Party.

- `index.html` — splash gate (click starts the music)
- `town.html` — the three chapters
- `haunted-harvest.css` — all styles, palette in CSS variables
- `assets/` — images and fonts (fonts load from Google Fonts)
